  - Add pets_kg to CategoryBreakdown in FootprintResult

  - Total: transport + food + home + pets
  - Update vs_national_avg calculation (national avg stays 60.5, pets are extra)

  Do NOT change the API endpoint path or HTTP method — only the schemas and calculation logic.
