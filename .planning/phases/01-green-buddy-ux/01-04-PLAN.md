  <name>Task 1: Extend actions-engine with new action types and CO2 delta tracking</name>
  <files>actions-engine/app/models.py, actions-engine/app/schemas.py, actions-engine/app/service.py, actions-engine/app/router.py, actions-engine/app/repository.py</files>
  <action>
  Update actions-engine to support new action types:

  **models.py** — Add/update ActionLog model:
  - id (UUID, PK)
  - user_id (UUID, indexed)
  - action_type: enum (meal, trip, grocery, clothing, appliance)
  - description: text (user input or AI-generated summary)
  - co2_delta_kg: float (positive = emission, negative = saving vs baseline)
  - image_analysis_id: UUID nullable (reference to image analysis if photo-based)
  - metadata_json: JSON (flexible — stores items, distances, etc.)
  - created_at: datetime

  **schemas.py:**
  - LogActionRequest: action_type, description (optional), co2_delta_kg, image_analysis_id (optional), metadata (optional dict)
  - ActionLogResponse: all fields from model
  - DailyActionsResponse: date, actions (list), total_co2_delta_kg
  - ActionType enum: meal, trip, grocery, clothing, appliance

  **service.py:**
  - log_action(user_id, request) → create ActionLog entry
  - get_daily_actions(user_id, date) → list of actions for that day with total delta
  - get_weekly_summary(user_id) → aggregated CO2 deltas by action_type

  **router.py:**
  - POST /api/v1/actions/log → log new action
  - GET /api/v1/actions/daily?date=YYYY-MM-DD → daily actions
  - GET /api/v1/actions/weekly → weekly summary

  Keep existing catalogue/ranking/streak endpoints intact.
  </action>
